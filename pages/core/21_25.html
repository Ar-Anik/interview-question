21global vs nonlocal

global এবং nonlocal-এর পার্থক্য কী?

দুটিই function-এর ভিতর থেকে outer scope-এর variable-এ assignment করার জন্য ব্যবহৃত হয়, কিন্তু target scope আলাদা।

  • global: current module-এর global variable-কে refer করে।
  • nonlocal: nested function-এর nearest enclosing function scope-এর existing variable-কে refer করে।

global example

count = 10

def update():
    global count
    count = 20

update()
print(count)  # 20

global count এর কারণে update()-এর ভিতরের assignment module-level count-কে target করে।

nonlocal example

def outer():
    count = 0

    def inner():
        nonlocal count
        count += 1

    inner()
    inner()
    return count

print(outer())  # 2

এখানে count global নয়; এটি outer()-এর local variable। inner() থেকে nonlocal দিয়ে সেটি modify করা হয়েছে।

global → module/global scope nonlocal → enclosing function scope

nonlocal ব্যবহার করলে enclosing function scope-এ matching existing binding থাকতে হবে।

Interview Answerglobal function-এর ভিতর থেকে module-level global variable-কে refer বা modify করতে ব্যবহৃত হয়। nonlocal nested function-এর ভিতর থেকে nearest enclosing function-এর variable modify করতে ব্যবহৃত হয়।
22Comprehensions

Comprehension কী?

Comprehension হলো Python-এর concise syntax, যার মাধ্যমে existing iterable থেকে নতুন collection তৈরি করা যায়। Common forms হলো list, set, dictionary comprehension এবং generator expression.

List comprehension

numbers = [1, 2, 3, 4, 5]
squares = [x * x for x in numbers]
print(squares)
# [1, 4, 9, 16, 25]

Condition সহ

numbers = [1, 2, 3, 4, 5, 6]
even_numbers = [x for x in numbers if x % 2 == 0]
print(even_numbers)
# [2, 4, 6]

Set comprehension

numbers = [1, 2, 2, 3, 3, 4]
unique_squares = {x * x for x in numbers}
print(unique_squares)
# {1, 4, 9, 16}

Dictionary comprehension

numbers = [1, 2, 3]
squares = {x: x * x for x in numbers}
print(squares)
# {1: 1, 2: 4, 3: 9}

Generator expression

numbers = [1, 2, 3]
squares = (x * x for x in numbers)

Generator expression result পুরো collection হিসেবে একসাথে materialize না করে values প্রয়োজন অনুযায়ী produce করতে পারে।

Logic খুব complex হলে comprehension-এর বদলে normal for loop বেশি readable হতে পারে।

Interview AnswerComprehension হলো Python-এর concise syntax যার মাধ্যমে iterable থেকে নতুন collection তৈরি করা যায়। List, set ও dictionary comprehension আছে; generator expression lazyভাবে values produce করতে পারে।
23Iterables vs iterators

Iterable এবং iterator-এর পার্থক্য কী?

Iterable হলো এমন object যার elements-এর ওপর iterate করা যায়। সাধারণত iter() দিয়ে iterable থেকে iterator পাওয়া যায়।

Iterator iteration-এর current state ধরে রাখে এবং next() দিয়ে একবারে পরবর্তী value দেয়। শেষ হলে StopIteration raise করে।

numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))  # 10
print(next(iterator))  # 20
print(next(iterator))  # 30

Iterator protocol

Iterator object সাধারণত __iter__() এবং __next__() implement করে। Iterator-এর __iter__() সাধারণত নিজেকেই return করে।

Iterable ↓ iter() Iterator ↓ next() Next value ↓ next() Next value ↓ StopIteration

List, tuple, set ইত্যাদি iterable container নিজে iterator নয়। তবে iterator নিজেও iterable, কারণ iterator protocol-এ __iter__() থাকে।

Interview AnswerIterable হলো এমন object যেটা থেকে iter() দিয়ে iterator পাওয়া যায়। Iterator iteration state ধরে রাখে এবং next() দিয়ে পরবর্তী value দেয়; শেষ হলে StopIteration raise করে।
24Generators

Generator কী?

Generator হলো এমন একটি mechanism, যার মাধ্যমে function বা expression values একসাথে materialize না করে একটি করে produce করতে পারে। Generator সাধারণত lazy evaluation ব্যবহার করে।

Generator function

def numbers():
    yield 1
    yield 2
    yield 3

gen = numbers()

print(next(gen))  # 1
print(next(gen))  # 2
print(next(gen))  # 3

Generator function call করলে একটি generator object পাওয়া যায়। next() call করলে execution শুরু/resume হয় এবং পরবর্তী yield-এ পৌঁছালে value produce করে।

কেন useful?

  • বড় data item-by-item process করা যায়।
  • পুরো sequence একসাথে memory-তে materialize না করেও কাজ করা যায়।
  • File processing, streaming এবং large sequences-এর মতো use case-এ useful।
def read_numbers():
    for number in range(1_000_000):
        yield number

for number in read_numbers():
    if number == 3:
        break

Generator “সবসময় কম memory ব্যবহার করবে”—এমন absolute claim ঠিক নয়। এটি lazyভাবে values produce করার সুযোগ দেয়; actual memory usage পুরো computation-এর ওপর নির্ভর করে।

Interview AnswerGenerator এমন একটি iterator-producing mechanism যা values lazyভাবে একবারে একটি করে produce করে। সাধারণত yield ব্যবহার করে generator function তৈরি করা হয়।
25yield

yield কী?

yield একটি function-কে generator function বানায়। এটি value produce করে এবং function-এর current execution state suspend করে। পরে generator resume হলে execution পরবর্তী statement থেকে চলতে থাকে।

def demo():
    print("Start")
    yield 10

    print("Middle")
    yield 20

    print("End")

gen = demo()

print(next(gen))
print(next(gen))

Flow:

demo() ↓ generator object তৈরি ↓ next(gen) ↓ "Start" ↓ yield 10 ↓ pause ↓ next(gen) ↓ resume ↓ "Middle" ↓ yield 20 ↓ pause

return বনাম yield

def normal():
    return 10

def generator():
    yield 10
  • return function-এর execution শেষ করে এবং result return করে।
  • yield value produce করে এবং generator-এর execution suspend করে; পরে resume করা যায়।

Generator শেষ হলে

আর কোনো value না থাকলে iteration শেষ হয় এবং StopIteration signal করা হয়। Generator function-এ return value থাকলে সেটি StopIteration.value-এর মাধ্যমে পাওয়া যেতে পারে।

def example():
    yield 1
    return "done"

gen = example()
print(next(gen))  # 1

try:
    next(gen)
except StopIteration as exc:
    print(exc.value)  # done

yield শুধু “return-এর মতো” নয়। মূল পার্থক্য হলো yield execution state suspend করে এবং generator পরে সেই state থেকে resume করতে পারে।

Interview Answeryield generator function-এ value produce করে এবং current execution state suspend করে। পরবর্তী next() call-এ generator সেই অবস্থান থেকে resume করে এবং পরবর্তী yield পর্যন্ত execute করে।
