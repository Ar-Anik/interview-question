Interview strategy: প্রথমে definition → তারপর কীভাবে কাজ করে → ছোট example → শেষে interview answer। Implementation-specific বিষয়কে language-level rule হিসেবে বলা এড়িয়ে চলুন।
11 List vs tuple

List এবং tuple-এর পার্থক্য কী?

দুটিই ordered sequence এবং index দিয়ে element access করা যায়। প্রধান পার্থক্য হলো list mutable, আর tuple immutable। 

# List
items = [10, 20, 30]
items[0] = 100
items.append(40)

# Tuple
point = (10, 20, 30)
# point[0] = 100  # TypeError

কখন কোনটি?

  • List: collection-এর content পরিবর্তন করতে হলে।
  • Tuple: fixed/immutable sequence represent করতে হলে।
  • Tuple-এর element-গুলো hashable হলে tuple-কে dictionary key বা set element হিসেবে ব্যবহার করা যেতে পারে।

Tuple সাধারণত list-এর তুলনায় “বেশি immutable” ধরনের semantic দেয়, কিন্তু শুধু tuple হওয়াই সবসময় faster বা memory-efficient হবে—এমন blanket claim করা উচিত নয়; use case এবং data-এর ওপর performance নির্ভর করে।

Interview Answer List এবং tuple দুটিই ordered sequence। List mutable, তাই এর elements পরিবর্তন, add বা remove করা যায়। Tuple immutable, তাই tuple-এর existing elements পরিবর্তন করা যায় না। Fixed collection-এর জন্য tuple এবং পরিবর্তনশীল collection-এর জন্য list ব্যবহার করা যায়।
12 Set vs list

Set এবং list-এর পার্থক্য কী?

List ordered sequence এবং duplicate element রাখতে পারে। Set হলো unique elements-এর collection এবং set-এর elements hashable হতে হয়। 

items = [1, 2, 2, 3, 1]
print(items)       # [1, 2, 2, 3, 1]

numbers = {1, 2, 2, 3, 1}
print(numbers)     # {1, 2, 3}

মূল পার্থক্য

  • List duplicate রাখে; set duplicate রাখে না।
  • List indexing/slicing support করে; set indexing বা slicing support করে না।
  • Set membership testing-এর জন্য hash-based implementation ব্যবহার করে; average-case lookup সাধারণত O(1)।
  • List membership search সাধারণত O(n)।

“Set unordered” বলা পুরোনো interview shorthand হিসেবে শোনা যায়। গুরুত্বপূর্ণ rule হলো set indexing-এর মাধ্যমে positional order access করার জন্য designed নয়; set-এর iteration order-এর ওপর application logic নির্ভর করা উচিত নয়। Python-এর dict-এর মতো set-এর insertion-order guarantee ধরে নেওয়া উচিত নয়।

Interview Answer List একটি ordered sequence এবং duplicate রাখতে পারে, আর set unique hashable elements রাখে। List indexing support করে, set করে না। Membership checking-এর জন্য set সাধারণত বেশি efficient, কারণ এটি hash-based lookup ব্যবহার করে।
13 Dictionary internals

Python dictionary internally কীভাবে কাজ করে?

Python dictionary হলো mapping type। CPython-এ dictionary একটি hash table-based data structure। Key থেকে hash value বের করে key/value entry locate করার জন্য hash table ব্যবহার করা হয়। 

key
 ↓
hash(key)
 ↓
hash-table lookup
 ↓
matching key
 ↓
value

Example

user = {
    "id": 101,
    "name": "Anik"
}

print(user["name"])

"name" key-এর hash ব্যবহার করে dictionary lookup করে। Hash collision হলে implementation এমনভাবে collision handle করে যাতে equality check-এর মাধ্যমে correct key নির্ধারণ করা যায়।

Python 3.7+ language specification অনুযায়ী normal dict insertion order preserve করে। তবে dictionary-কে শুধু “ordered array” হিসেবে ভাবা ভুল; এটি mapping এবং hash-table-based implementation ব্যবহার করে।

Dictionary internals-এর exact memory layout এবং implementation details CPython version অনুযায়ী পরিবর্তিত হতে পারে। Interview-এ “hash table based” এবং key hashability/equality—এই core concept-এ focus করা নিরাপদ।

Interview Answer Python dict একটি mapping type এবং CPython-এ hash table-based। Dictionary key-এর hash ব্যবহার করে lookup করে এবং collision হলে equality check-এর মাধ্যমে correct key identify করে। Dictionary insertion order preserve করে, কিন্তু এর core purpose হলো key থেকে value mapping করা।
14 Hashing

Hashing কী?

Hashing হলো একটি object থেকে একটি integer hash value তৈরি করার process। Python-এ hash(obj) function দিয়ে কোনো hashable object-এর hash value পাওয়া যায়। 

print(hash("python"))
print(hash(100))

Hash-based data structures যেমন dict এবং set lookup efficiently করার জন্য hash ব্যবহার করে।

সব object কি hashable?

না। সাধারণভাবে hashable object-এর hash value তার lifetime-এ পরিবর্তন করা উচিত নয় এবং object equality-এর সাথে hash-এর একটি গুরুত্বপূর্ণ contract আছে: 

a == b  →  hash(a) == hash(b)

উল্টোটা সত্য নয়: দুইটি object-এর hash একই হলেই তারা equal—এমন নয়। এটাকেই hash collision-এর context-এ বোঝা যায়।

Mutable object সাধারণত hashable নয়, যদি mutation-এর কারণে hash/equality পরিবর্তিত হতে পারে। List যেমন hashable নয়; immutable এবং appropriate equality semantics থাকা কিছু object যেমন str এবং int hashable।

Interview Answer Hashing হলো object থেকে integer hash value তৈরি করা। Dict এবং set-এর মতো hash-based data structure এই hash ব্যবহার করে lookup efficiently করে। Hashable object-এর ক্ষেত্রে equal objects-এর hash একই হতে হবে, কিন্তু একই hash মানেই objects equal—এমন নয়।
15 __hash__

__hash__ কী?

__hash__ হলো special method, যা কোনো object-এর hash value নির্ধারণে ব্যবহৃত হয়। hash(obj) call করলে Python object-এর hashing protocol ব্যবহার করে। 

class User:
    def __init__(self, user_id):
        self.user_id = user_id

    def __eq__(self, other):
        if not isinstance(other, User):
            return NotImplemented
        return self.user_id == other.user_id

    def __hash__(self):
        return hash(self.user_id)

এখানে একই user_id থাকা User objects equality অনুযায়ী equal হবে এবং তাদের hash-ও একই হবে।

সবচেয়ে গুরুত্বপূর্ণ rule

যদি a == b হয়, তাহলে hash(a) == hash(b) হতে হবে। কিন্তু hash(a) == hash(b) হলে a == b হওয়া বাধ্যতামূলক নয়।

কোনো object dictionary key বা set element হিসেবে ব্যবহার করা হলে তার equality-relevant state object-এর lifetime-এ পরিবর্তন না হওয়া গুরুত্বপূর্ণ। নইলে object hash table-এ insert করার পর lookup behavior problematic হতে পারে।

Python 3-এ কোনো class __eq__ define করে কিন্তু appropriate __hash__ না দেয়, সাধারণত সেই class unhashable হয়ে যায়। এটি mutable/equality semantics নিরাপদ রাখার একটি গুরুত্বপূর্ণ behavior।

Interview Answer __hash__ special method object-এর hash value define করে। Dict key বা set element হিসেবে ব্যবহারের জন্য object hashable হতে হয়। Equality অনুযায়ী equal objects-এর hash অবশ্যই equal হতে হবে।
16 Shallow copy vs deep copy

Shallow copy এবং deep copy কী?

Shallow copy নতুন outer/container object তৈরি করে, কিন্তু nested objects-এর references copy করে। Deep copy recursively nested objects-ও copy করার চেষ্টা করে, তাই copied structure সাধারণত original-এর nested mutable objects share করে না। 

original = [[1, 2], [3, 4]]

shallow = original.copy()

shallow[0].append(99)

print(original)  # [[1, 2, 99], [3, 4]]
print(shallow)   # [[1, 2, 99], [3, 4]]

এখানে outer list আলাদা হলেও inner list একই object। তাই inner list mutate করলে দুই জায়গাতেই পরিবর্তন দেখা যায়। 

import copy

original = [[1, 2], [3, 4]]
deep = copy.deepcopy(original)

deep[0].append(99)

print(original)  # [[1, 2], [3, 4]]
print(deep)      # [[1, 2, 99], [3, 4]]

Deep copy মানে “প্রতিটি object সবসময় byte-for-byte নতুন করে তৈরি” নয়। Python-এর copy module-এর rules অনুযায়ী objects copy করা হয়; কিছু object-এর copying আলাদা behavior দিতে পারে।

Interview Answer Shallow copy নতুন outer object তৈরি করে কিন্তু nested object-এর references share করতে পারে। Deep copy recursively nested objects copy করে, তাই nested mutable data সাধারণত independent হয়।
17 copy.copy() vs copy.deepcopy()

copy.copy() এবং copy.deepcopy()-এর পার্থক্য

দুটিই Python-এর copy module-এর function। 

import copy

a = [[1, 2], [3, 4]]

b = copy.copy(a)       # shallow copy
c = copy.deepcopy(a)   # deep copy

copy.copy()

Top-level/outer object-এর shallow copy তৈরি করে। Nested objects-এর references সাধারণত original-এর সাথেই shared থাকে।

copy.deepcopy()

Object graph recursively copy করার চেষ্টা করে। একই object graph-এর repeated references preserve করার জন্য deep-copy process একটি memoization mechanism ব্যবহার করে, যাতে একই original object অপ্রয়োজনে বারবার copy না হয় এবং recursive structures handle করা যায়। 

import copy

original = [[1, 2], [3, 4]]

a = copy.copy(original)
b = copy.deepcopy(original)

print(a is original)       # False
print(a[0] is original[0]) # True

print(b is original)       # False
print(b[0] is original[0]) # False
Interview Answer copy.copy() shallow copy করে—outer object নতুন হলেও nested references share হতে পারে। copy.deepcopy() nested object graph recursively copy করার চেষ্টা করে, তাই nested mutable objects সাধারণত independent হয়।
18 *args and **kwargs

*args এবং **kwargs কী?

Function definition-এ *args অতিরিক্ত positional arguments collect করে tuple হিসেবে, আর **kwargs অতিরিক্ত keyword arguments collect করে dictionary হিসেবে। 

def example(*args, **kwargs):
    print(args)
    print(kwargs)

example(10, 20, name="Anik", role="Engineer")

# args   -> (10, 20)
# kwargs -> {"name": "Anik", "role": "Engineer"}

Unpacking-ও * এবং ** দিয়ে করা যায়

numbers = [10, 20, 30]
data = {"name": "Anik", "role": "Engineer"}

print(*numbers)

def greet(name, role):
    print(name, role)

greet(**data)

তাই * এবং **-এর অর্থ context-এর ওপর নির্ভর করে: function definition-এ এগুলো arguments collect করতে পারে, আর function call-এ iterable/mapping unpack করতে পারে।

Interview Answer *args function-এর extra positional arguments tuple হিসেবে collect করে এবং **kwargs extra keyword arguments dictionary হিসেবে collect করে। Function call-এর সময় * iterable unpack এবং ** mapping unpack করতেও ব্যবহার করা যায়।
19 Default mutable arguments

Default mutable argument problem কী?

Python-এ function definition-এর সময় default argument value evaluate করা হয় এবং function object-এর সাথে সংরক্ষিত থাকে। তাই default value যদি mutable object হয়, multiple function call একই object share করতে পারে। 

def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("A"))  # ['A']
print(add_item("B"))  # ['A', 'B']
print(add_item("C"))  # ['A', 'B', 'C']

এখানে [] প্রতিবার function call-এ নতুন list তৈরি করছে না। একই default list successive calls-এ reuse হচ্ছে।

Recommended solution

def add_item(item, items=None):
    if items is None:
        items = []

    items.append(item)
    return items

print(add_item("A"))  # ['A']
print(add_item("B"))  # ['B']

None একটি immutable/sentinel-like default value হিসেবে ব্যবহার করে function-এর ভিতরে প্রয়োজন অনুযায়ী নতুন list তৈরি করা যায়।

Default argument-এর behavior বোঝার সবচেয়ে গুরুত্বপূর্ণ point হলো: default expressions function call-এর সময় নয়, function definition-এর সময় evaluate হয়।

Interview Answer Python function-এর default arguments definition time-এ evaluate হয়। তাই mutable default যেমন [] ব্যবহার করলে multiple calls একই object share করতে পারে। সাধারণ solution হলো None default দিয়ে function-এর ভিতরে নতুন mutable object তৈরি করা।
20 LEGB scope

LEGB rule কী?

Python কোনো name lookup করার সময় সাধারণভাবে LEGB order অনুসরণ করে:

  • L — Local: current function-এর local scope
  • E — Enclosing: nested function-এর outer function scope
  • G — Global: current module/global scope
  • B — Built-in: Python-এর built-in names
x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)

    inner()

outer()

inner()-এর ভিতরে x খোঁজা হলে প্রথমে Local scope-এ পাওয়া যায়, তাই output হবে local। Local-এ না থাকলে Enclosing, তারপর Global, তারপর Built-in scope-এ lookup হয়।

global এবং nonlocal

x = 10

def update_global():
    global x
    x = 20

def outer():
    count = 0

    def inner():
        nonlocal count
        count += 1

    inner()
    return count

global module-level global name-কে refer/assign করার জন্য এবং nonlocal nearest enclosing function scope-এর existing name-কে refer/assign করার জন্য ব্যবহৃত হয়।

Interview Answer LEGB হলো Python name lookup rule: Local → Enclosing → Global → Built-in। Python এই order-এ name খোঁজে। nonlocal enclosing function-এর variable modify করতে এবং global module-level global variable-এর সাথে কাজ করতে ব্যবহার করা হয়।
