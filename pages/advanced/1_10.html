Python Advanced Interview Questions

Decorators, Closures, Functions, Context Managers, Generators & Iterators

সংজ্ঞা

Decorator হলো এমন একটি function যা অন্য একটি function বা callable-কে input হিসেবে নিয়ে তার behavior পরিবর্তন বা extend করে এবং সাধারণত একটি নতুন callable return করে।

মূল function-এর source code পরিবর্তন না করেই তার execution-এর আগে বা পরে additional behavior যোগ করা যায়।

সহজ ধারণা

ধরা যাক একটি function-এর কাজ হলো শুধু data process করা। কিন্তু function call করার আগে logging এবং function শেষ হওয়ার পরে execution time measure করা দরকার।

মূল function-এর ভিতরে logging code না লিখে decorator ব্যবহার করে সেই behavior যোগ করা যায়।

Basic Example

def my_decorator(func):

    def wrapper():
        print("Before function")
        func()
        print("After function")

    return wrapper


def hello():
    print("Hello")


hello = my_decorator(hello)

hello()

Output:

Before function
Hello
After function

@ Syntax

Python decorator-এর জন্য সাধারণত @ syntax ব্যবহার করা হয়। 

def my_decorator(func):

    def wrapper():
        print("Before function")
        func()
        print("After function")

    return wrapper


@my_decorator
def hello():
    print("Hello")

এই syntax-এর অর্থ কার্যত: 

hello = my_decorator(hello)
Important: Decorator নিজে function call করে না। Decorator একটি function গ্রহণ করে এবং সাধারণত একটি নতুন wrapper function return করে।
Interview Answer:
Decorator is a callable that takes another callable and extends or modifies its behavior without changing the original callable's source code.

Decorator-এর internal flow

Decorator বুঝতে প্রথমে function-এর একটি গুরুত্বপূর্ণ property বুঝতে হবে: Python-এ function একটি object।

তাই একটি function অন্য function-এর argument হতে পারে এবং একটি function অন্য function return করতে পারে। 

def decorator(func):

    def wrapper(*args, **kwargs):
        print("Before")
        result = func(*args, **kwargs)
        print("After")
        return result

    return wrapper


@decorator
def add(a, b):
    return a + b

Python যখন @decorator দেখে, function definition-এর পরে কার্যত: 

add = decorator(add)

ফলে add-এ original function সরাসরি থাকে না; decorator থেকে return হওয়া wrapper callable থাকে।

Arguments কীভাবে handle হয়?

Decorator যেন বিভিন্ন signature-এর function handle করতে পারে, তাই সাধারণত: 

def wrapper(*args, **kwargs):
    return func(*args, **kwargs)

এখানে *args positional arguments এবং **kwargs keyword arguments capture করে।

Return value গুরুত্বপূর্ণ কেন?

Wrapper-এর ভিতরে original function call করার পর result return না করলে original function-এর return value হারিয়ে যাবে। 

def decorator(func):

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        return result

    return wrapper

functools.wraps

Decorator ব্যবহার করলে wrapper function-এর metadata original function-এর metadata-কে replace করতে পারে। যেমন __name__ এবং __doc__। 

from functools import wraps


def decorator(func):

    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)

    return wrapper
Flow:
Original function → decorator receives it → decorator creates wrapper → wrapper is returned → original name points to wrapper
Interview Answer:
A decorator works by receiving a callable, creating or returning another callable that adds behavior, and replacing the original function reference with that returned callable. The @decorator syntax is equivalent to func = decorator(func).

সংজ্ঞা

Closure হলো এমন একটি inner function যা তার enclosing scope-এর variable-কে reference করে এবং enclosing function execution শেষ হওয়ার পরেও সেই variable-এর access ধরে রাখে।

Example

def outer():

    message = "Hello"

    def inner():
        print(message)

    return inner


func = outer()

func()

এখানে outer() execution শেষ হয়ে গেছে। তারপরও inner() যখন call হচ্ছে, তখন message access করতে পারছে।

কেন সম্ভব?

কারণ inner function তার enclosing scope-এর variable-এর reference ধরে রাখে।

সেই captured variable-কে closure-এর __closure__ attribute-এর মাধ্যমে inspect করা যায়। 

def outer():
    x = 10

    def inner():
        return x

    return inner


func = outer()

print(func())
print(func.__closure__)

Closure-এর practical example

def multiplier(n):

    def multiply(value):
        return value * n

    return multiply


double = multiplier(2)
triple = multiplier(3)

print(double(10))
print(triple(10))

এখানে double function n = 2 এবং triple function n = 3 capture করে রেখেছে।

Closure-এর জন্য তিনটি বিষয় গুরুত্বপূর্ণ:

1. একটি nested function থাকতে হবে।
2. Inner function enclosing scope-এর variable ব্যবহার করবে।
3. Inner function enclosing function-এর বাইরে survive করবে।
Interview Answer:
A closure is a function that remembers and retains access to variables from its enclosing lexical scope even after the enclosing function has finished execution.

সংজ্ঞা

Python-এ function হলো first-class object। অর্থাৎ function-কে সাধারণ object-এর মতো ব্যবহার করা যায়।

Function কী কী করতে পারে?

  • Variable-এ assign করা যায়।
  • অন্য function-এ argument হিসেবে পাঠানো যায়।
  • Function থেকে return করা যায়।
  • List, dictionary বা অন্য data structure-এ রাখা যায়।

Variable-এ function রাখা

def greet():
    return "Hello"


message = greet

print(message())

এখানে message এবং greet একই function object reference করছে।

Function হিসেবে argument

def greet():
    return "Hello"


def execute(func):
    return func()


print(execute(greet))

Function return করা

def outer():

    def inner():
        return "Hello"

    return inner


func = outer()

print(func())

First-class function বনাম Higher-order function

এই দুইটি concept related কিন্তু একই নয়।

First-class function হলো language-এর capability—function object হিসেবে ব্যবহারযোগ্য।

Higher-order function হলো এমন function যা function গ্রহণ করে অথবা function return করে।

Interview Answer:
Python treats functions as first-class objects, meaning functions can be assigned to variables, passed as arguments, returned from other functions, and stored in data structures.

সংজ্ঞা

Higher-order function হলো এমন function যা অন্তত একটি function-কে argument হিসেবে গ্রহণ করে অথবা একটি function return করে।

Example 1 — Function গ্রহণ করা

def square(x):
    return x * x


def apply_operation(func, value):
    return func(value)


result = apply_operation(square, 5)

print(result)

এখানে apply_operation একটি function argument গ্রহণ করছে। তাই এটি higher-order function।

Example 2 — Function return করা

def create_multiplier(n):

    def multiply(x):
        return x * n

    return multiply


double = create_multiplier(2)

print(double(5))

create_multiplier একটি function return করছে, তাই এটিও higher-order function।

Built-in Example

Python-এর map(), filter() ইত্যাদি higher-order function-এর উদাহরণ। 

numbers = [1, 2, 3, 4]

result = map(lambda x: x * 2, numbers)

print(list(result))

Decorator-এর সাথে সম্পর্ক

Decorator সাধারণত higher-order function-এর একটি practical use case, কারণ decorator একটি function গ্রহণ করে এবং একটি callable return করে।

মনে রাখার সহজ নিয়ম:
Function → argument হিসেবে নেয় অথবা function → return করে = Higher-order function.
Interview Answer:
A higher-order function is a function that takes one or more functions as arguments or returns a function as its result.

সংজ্ঞা

Context Manager হলো এমন mechanism যা কোনো resource ব্যবহারের আগে setup এবং ব্যবহারের পরে cleanup operation-এর lifecycle manage করে।

কেন দরকার?

File, database transaction, lock ইত্যাদি resource ব্যবহারের সময় cleanup নিশ্চিত করা গুরুত্বপূর্ণ।

উদাহরণ হিসেবে file open করার পর file close করা দরকার। কোনো exception হলেও cleanup হওয়া উচিত।

Without Context Manager

file = open("data.txt", "r")

try:
    data = file.read()
finally:
    file.close()

With Context Manager

with open("data.txt", "r") as file:
    data = file.read()

with block শেষ হলে file automatically close হয়—even if block-এর ভিতরে exception ঘটে।

Context Manager কোথায় ব্যবহৃত হয়?

  • File handling
  • Database connection বা transaction management
  • Thread Lock
  • Temporary resource management
  • Custom resource lifecycle management
Context Manager-এর মূল উদ্দেশ্য শুধু file close করা নয়। মূল উদ্দেশ্য হলো resource-এর setup এবং cleanup-এর lifecycle নির্ভরযোগ্যভাবে manage করা।
Interview Answer:
A context manager manages the setup and cleanup of a resource around a block of code, usually through the with statement.

with কী?

with statement একটি context manager-এর lifecycle manage করার জন্য ব্যবহৃত হয়।

এটি context-এর শুরুতে setup এবং context-এর শেষে cleanup করার standard structure প্রদান করে।

File Example

with open("example.txt", "r") as file:
    content = file.read()

এখানে open() একটি file object return করে, যা context manager protocol support করে।

with block শেষ হলে file close করার cleanup operation automatically execute হয়।

Exception হলেও cleanup

with open("example.txt", "r") as file:

    data = file.read()

    raise ValueError("Something went wrong")

Exception ঘটলেও context manager-এর exit operation execute হয়, তাই resource cleanup করার সুযোগ থাকে।

Conceptual Flow

Enter context
      ↓
Run with-block
      ↓
Exception হয়েছে?
   ↙        ↘
 Yes         No
  ↓           ↓
Exit       Exit
  ↓           ↓
Cleanup     Cleanup

এখানে __enter__() context শুরু করে এবং __exit__() context শেষ করে।

Interview Answer:
The with statement is used to work with context managers and ensures that setup and cleanup operations are handled automatically around a block of code.

Context Manager Protocol

একটি class-কে context manager হিসেবে ব্যবহার করতে হলে synchronous context manager-এর ক্ষেত্রে সাধারণত __enter__() এবং __exit__() implement করা হয়।

__enter__()

with block শুরু হওয়ার সময় __enter__() call হয়।

এই method-এর return value as variable-এ assign হয়। 

class MyContext:

    def __enter__(self):
        print("Entering context")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Exiting context")


with MyContext() as obj:
    print("Inside context")

__exit__()

with block শেষ হওয়ার সময় __exit__() call হয়।

এর তিনটি গুরুত্বপূর্ণ exception-related parameter থাকে:

  • exc_type
  • exc_value
  • traceback

কোনো exception না হলে এগুলো None হয়।

Exception handling

class MyContext:

    def __enter__(self):
        print("Start")
        return self

    def __exit__(self, exc_type, exc_value, traceback):

        if exc_type:
            print("Exception:", exc_value)

        print("Cleanup")

        return False

__exit__() থেকে True return করলে exception suppress করা হয়।

False অথবা None return করলে exception সাধারণভাবে propagate করে।

Important: __exit__() থেকে True return করার অর্থ exception-কে suppress করা। তাই এটি ইচ্ছাকৃতভাবে ব্যবহার করা উচিত।
Interview Answer:
__enter__() runs when entering a context and returns the value bound to the as target. __exit__() runs when leaving the context and handles cleanup and possible exceptions.

সংজ্ঞা

contextlib হলো Python-এর standard library module, যা context manager তৈরি ও ব্যবহারের জন্য utility প্রদান করে।

বিশেষ করে ছোট বা straightforward context manager-এর জন্য class লিখে __enter__() এবং __exit__() implement করার পরিবর্তে @contextmanager ব্যবহার করা যায়।

@contextmanager

from contextlib import contextmanager


@contextmanager
def my_context():

    print("Start")

    try:
        yield
    finally:
        print("Cleanup")


with my_context():
    print("Inside context")

yield-এর ভূমিকা

এখানে yield context-এর boundary নির্দেশ করে।

সাধারণভাবে flow: 

Code before yield
       ↓
with block
       ↓
Code after yield
       ↓
Cleanup

finally ব্যবহার করায় context block-এর ভিতরে exception হলেও cleanup code execute হওয়ার সুযোগ থাকে।

Value provide করা

from contextlib import contextmanager


@contextmanager
def database_connection():

    connection = create_connection()

    try:
        yield connection
    finally:
        connection.close()


with database_connection() as connection:
    connection.execute("SELECT ...")

বাস্তব application-এ resource creation এবং cleanup logic encapsulate করতে এই pattern ব্যবহার করা যায়।

contextlib-এর আরও কিছু utility

  • contextmanager
  • closing
  • suppress
  • ExitStack
Important: @contextmanager function অবশ্যই generator-based context manager pattern অনুসরণ করে; context-এর আগে setup, yield, এবং পরে cleanup সাধারণত try/finally দিয়ে লেখা হয়।
Interview Answer:
contextlib is a standard-library module that provides utilities for creating and working with context managers. @contextmanager allows a generator function to define context setup, the context body boundary, and cleanup without explicitly writing a context-manager class.

Iterator কী?

Iterator হলো এমন object যার উপর next() call করে একবারে পরবর্তী value পাওয়া যায়।

একটি iterator সাধারণত __iter__() এবং __next__() implement করে। 

numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))

শেষ value-এর পরে next() call করলে StopIteration exception হয়।

Custom Iterator

class Counter:

    def __init__(self, limit):
        self.current = 0
        self.limit = limit

    def __iter__(self):
        return self

    def __next__(self):

        if self.current >= self.limit:
            raise StopIteration

        value = self.current
        self.current += 1

        return value


counter = Counter(3)

for value in counter:
    print(value)

Generator কী?

Generator হলো generator function বা generator expression থেকে তৈরি হওয়া iterator, যা সাধারণত yield ব্যবহার করে value produce করে। 

def numbers():

    yield 1
    yield 2
    yield 3


gen = numbers()

print(next(gen))
print(next(gen))
print(next(gen))

Generator-এর গুরুত্বপূর্ণ বৈশিষ্ট্য

  • Generator value একসাথে তৈরি করে না; প্রয়োজন অনুযায়ী produce করে।
  • yield function-এর execution state ধরে রাখে।
  • Large data process করার সময় memory efficient হতে পারে।
  • Generator object iterator protocol follow করে।

Generator বনাম Iterator

Generator
    ↓
Iterator protocol follow করে
    ↓
next() দিয়ে value পাওয়া যায়

তাই সবচেয়ে গুরুত্বপূর্ণ relationship হলো:

Every generator is an iterator, but every iterator is not a generator.

Memory Difference

ধরা যাক 1 থেকে 1,000,000 পর্যন্ত value process করতে হবে। 

numbers = [x for x in range(1_000_001)]

List comprehension পুরো list memory-তে তৈরি করে। 

numbers = (x for x in range(1_000_001))

Generator expression value প্রয়োজন অনুযায়ী produce করে। তাই পুরো sequence একসাথে memory-তে materialize করতে হয় না।

মূল পার্থক্য

  • Iterator হলো protocol/behavior-এর concept।
  • Generator হলো iterator তৈরি করার একটি সহজ Python mechanism।
  • Custom iterator-এ সাধারণত __iter__() এবং __next__() implement করতে হয়।
  • Generator function-এ সাধারণত yield ব্যবহার করলেই Python iterator behavior তৈরি করে।
Interview Answer:
An iterator is an object that follows the iterator protocol and produces values through __next__(). A generator is a convenient way to create an iterator using yield. Therefore, every generator is an iterator, but not every iterator is a generator.
