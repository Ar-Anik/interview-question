01Class vs Object — Class এবং Object-এর মধ্যে পার্থক্য কী?

মূল ধারণা

Class হলো user-defined type বা blueprint, যেখানে কোনো ধরনের object-এর data এবং behavior define করা হয়। Object হলো সেই class থেকে তৈরি হওয়া নির্দিষ্ট instance। Class বলে object-এর কী কী attribute ও method থাকতে পারে; object সেই structure অনুযায়ী নিজের state ধারণ করে।

সহজ উদাহরণ: `Car` class-এ `brand`, `color` এবং `start()` define করা থাকতে পারে। `Toyota`-র একটি গাড়ি এবং `Honda`-র আরেকটি গাড়ি হলো ওই class-এর আলাদা object।

Code Example

PYTHON 3
class Car:
    def __init__(self, brand, color):
        self.brand = brand
        self.color = color

    def start(self):
        return f"{self.brand} is starting"


car_one = Car("Toyota", "Black")
car_two = Car("Honda", "White")

print(car_one.brand)  # Toyota
print(car_two.brand)  # Honda
print(car_one.start())

Internal Working

  • class Car: execute হলে Python একটি class object তৈরি করে এবং নাম Car-কে সেই object-এর সঙ্গে bind করে।
  • Car(...) call করলে সাধারণত class-এর metaclass machinery object তৈরি করে; স্বাভাবিক ক্ষেত্রে __new__() allocation করে এবং __init__() নতুন object initialize করে।
  • car_one এবং car_two একই class-এর instance, কিন্তু তাদের instance attribute আলাদা।

Common Confusion

একটি class থেকে অনেক object তৈরি করা যায়। Class নিজে কোনো নির্দিষ্ট গাড়ি নয়; এটি গাড়ির object তৈরির structure। আবার Python-এ class-ও object—এটি একটি গুরুত্বপূর্ণ advanced detail।

Interview answer: Class হলো object তৈরির blueprint বা user-defined type; object হলো class-এর concrete instance, যার নিজস্ব state থাকতে পারে এবং class-এ define করা behavior ব্যবহার করতে পারে।
02What is __init__() in Python?

মূল ধারণা

__init__() হলো একটি special instance method, যেটি নতুন object তৈরি হওয়ার পর object-টিকে initialize করে। সাধারণত instance attribute-এর initial value এখানে set করা হয়। একে প্রায়ই constructor বলা হয়, তবে technicalভাবে Python-এর object creation method হলো __new__(); __init__() initializer।

Code Example

PYTHON 3
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

employee = Employee("Anik", 50000)

print(employee.name)    # Anik
print(employee.salary)  # 50000

কীভাবে কাজ করে?

  1. Employee("Anik", 50000) call করা হয়।
  2. Python class-এর __new__() call করে instance তৈরি করে।
  3. Instance তৈরি হলে Python সেই instance-কে প্রথম argument হিসেবে দিয়ে __init__() call করে।
  4. self.name ও self.salary assignment-এর মাধ্যমে instance-এর attribute তৈরি হয়।

গুরুত্বপূর্ণ নিয়ম

  • __init__() থেকে None return করতে হয়; অন্য value return করলে TypeError হয়। Explicit return না থাকলেও Python implicitভাবে None return করে।
  • একটি class-এ সাধারণত একটি কার্যকর __init__ definition থাকে। একই নামের method আবার define করলে আগের definition overwrite হয়।
  • Subclass চাইলে parent-এর initializer call করতে super().__init__(...) ব্যবহার করতে পারে।
INHERITANCE EXAMPLE
class Person:
    def __init__(self, name):
        self.name = name

class Developer(Person):
    def __init__(self, name, language):
        super().__init__(name)
        self.language = language
Common confusion: __init__() object allocate করে না। Object creation-এর কাজ __new__()-এর; __init__() তৈরি হওয়া instance initialize করে।
Interview answer: __init__() হলো initializer method, যা newly created instance-এর initial state set করে। Object allocation করে __new__(), তারপর initialization-এর জন্য __init__() চলে।
03What is self in Python?

মূল ধারণা

self হলো instance method-এর conventional first parameter। Method call-এর সময় যে instance দিয়ে method call করা হয়, Python সেই instance-টিকে automatically first argument হিসেবে pass করে। self Python keyword নয়; এটি প্রচলিত naming convention।

Code Example

PYTHON 3
class Student:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        return f"My name is {self.name}"

student = Student("Anik")

# Instance দিয়ে call
student.introduce()

# Class দিয়ে equivalent call
Student.introduce(student)

Internal Working: method binding

Class-এর function-কে instance-এর মাধ্যমে access করলে Python descriptor mechanism-এর মাধ্যমে একটি bound method তৈরি করে। এই bound method call করার সময় instance-টি প্রথম argument হিসেবে pass হয়। তাই student.introduce() কার্যত Student.introduce(student)-এর সমতুল্য।

কেন self প্রয়োজন?

  • কোন instance-এর attribute access বা update হবে, তা বোঝায়।
  • একই class-এর একাধিক instance-এর state আলাদা রাখতে সাহায্য করে।
  • Instance method-এর মধ্যে অন্য instance method call করা যায়, যেমন self.calculate_total()।
মনে রাখা জরুরি: self নামটি বাধ্যতামূলক syntax নয়, কিন্তু convention হিসেবে self ব্যবহার করাই Python community standard। অন্য নাম technically কাজ করলেও তা avoid করা উচিত।
Interview answer: self হলো current instance-কে reference করা instance-method parameter। Instance দিয়ে method call করলে Python instance-টিকে automatically pass করে; self keyword নয়, convention।
04Instance Variables vs Class Variables

মূল ধারণা

Instance variable নির্দিষ্ট object-এর state রাখে। সাধারণত self.attribute দিয়ে initialize বা assign করা হয়। Class variable class-এর namespace-এ define করা হয় এবং class-এর instance-গুলোর মধ্যে shared value হিসেবে ব্যবহৃত হতে পারে।

PYTHON 3
class Employee:
    company = "Divine IT"  # Class variable

    def __init__(self, name, salary):
        self.name = name          # Instance variable
        self.salary = salary      # Instance variable

emp1 = Employee("Rahim", 40000)
emp2 = Employee("Karim", 50000)

print(emp1.company)  # Divine IT
print(emp2.company)  # Divine IT

emp1.salary = 45000
Employee.company = "New Company"

print(emp1.salary)   # 45000
print(emp2.salary)   # 50000
print(emp1.company)  # New Company
print(emp2.company)  # New Company

Attribute lookup কীভাবে কাজ করে?

সাধারণ instance attribute read করার সময় Python প্রথমে instance-এর attribute storage-এ খোঁজে; না পেলে class এবং inheritance lookup chain-এ খোঁজে। তাই instance-এ company নামে নতুন attribute assign করলে class variable overwrite হয় না—instance-level attribute তৈরি হয় এবং সেটিই ওই instance-এর read-এ অগ্রাধিকার পায়।

SHADOWING EXAMPLE
class Employee:
    company = "Divine IT"

emp = Employee()
emp.company = "Personal Value"

print(emp.company)          # Personal Value
print(Employee.company)    # Divine IT

Mutable class variable-এর সতর্কতা

Class variable হিসেবে list বা dictionary রাখলে এবং instance থেকে সেটিকে mutate করলে shared object-টিই পরিবর্তিত হয়। ফলে সব instance সেই পরিবর্তন দেখতে পারে। Per-instance mutable data দরকার হলে __init__()-এর মধ্যে নতুন list/dict তৈরি করা উচিত।

SAFE INSTANCE DATA
class Team:
    def __init__(self):
        self.members = []  # প্রতিটি object-এর আলাদা list
Interview answer: Instance variable প্রতিটি object-এর নিজস্ব state রাখে; class variable class-level attribute, যা instance-গুলো সাধারণত sharedভাবে access করে। তবে instance assignment একই নামের instance attribute তৈরি করে class variable-কে shadow করতে পারে।
05Instance Method vs Class Method vs Static Method

তিন ধরনের method-এর মূল পার্থক্য

  • Instance method: প্রথম parameter convention অনুযায়ী self; instance state নিয়ে কাজ করে।
  • Class method: @classmethod দিয়ে declare করা হয়; প্রথম parameter convention অনুযায়ী cls, অর্থাৎ যে class দিয়ে method call হয়েছে।
  • Static method: @staticmethod দিয়ে declare করা হয়; automatic self বা cls পায় না। এটি class namespace-এর সঙ্গে সম্পর্কিত utility function হিসেবে রাখা যায়।
PYTHON 3
class Employee:
    company = "Divine IT"

    def __init__(self, name):
        self.name = name

    # Instance method
    def get_name(self):
        return self.name

    # Class method
    @classmethod
    def change_company(cls, new_name):
        cls.company = new_name

    # Static method
    @staticmethod
    def is_valid_name(name):
        return isinstance(name, str) and bool(name.strip())


employee = Employee("Anik")
print(employee.get_name())
Employee.change_company("Example Ltd")
print(Employee.company)
print(Employee.is_valid_name("Anik"))

Class method কেন useful?

একটি common use case হলো alternative constructor বা factory method। যেমন string থেকে Employee object তৈরি করা। এখানে cls ব্যবহার করায় subclass দিয়ে inherited class method call করলেও সাধারণত subclass-ই instantiate হয়।

ALTERNATIVE CONSTRUCTOR
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    @classmethod
    def from_string(cls, value):
        name, salary = value.split(",")
        return cls(name, int(salary))

emp = Employee.from_string("Anik,50000")

কখন কোনটি ব্যবহার করা হয়?

  • Instance-এর data read/update করতে: instance method।
  • Class-level state বা alternative constructor নিয়ে কাজ করতে: class method।
  • শুধু input নিয়ে কাজ করে, instance/class state লাগে না—এমন related utility: static method।
Common confusion: Static method শুধু class-এর ভেতরে লেখা বলে instance method হয়ে যায় না। এটিকে class বা instance—দুইভাবেই call করা যায়, কিন্তু Python automaticভাবে self/cls bind করে না।
Interview answer: Instance method instance পায়, class method calling class পায়, আর static method automatic কোনো instance বা class argument পায় না। পার্থক্যটি মূলত method binding এবং কোন state access করার প্রয়োজন তার উপর নির্ভর করে।
06What is Encapsulation in Python?

মূল ধারণা

Encapsulation হলো data এবং সেই data-র উপর কাজ করা behavior-কে একটি unit—যেমন class—এর মধ্যে রাখা, এবং object-এর state কীভাবে access বা change হবে তার interface নির্ধারণ করা। এর উদ্দেশ্য হলো valid state বজায় রাখা, implementation detail আড়ালে রাখা এবং uncontrolled modification কমানো।

Python-এ access convention

  • name: public attribute—সাধারণভাবে সরাসরি access করার জন্য।
  • _name: single leading underscore—এটি non-public/internal ব্যবহারের convention; language-level access restriction নয়।
  • __name: double leading underscore—class-এর ভেতরে name mangling হয়, যেমন _Account__balance। এটি কঠোর private access control নয়; accidental name collision কমাতে সাহায্য করে।

Property দিয়ে controlled access

PYTHON 3
class BankAccount:
    def __init__(self, initial_balance):
        self._balance = 0
        self.deposit(initial_balance)

    @property
    def balance(self):
        return self._balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Amount must be positive")
        self._balance += amount

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("Amount must be positive")
        if amount > self._balance:
            raise ValueError("Insufficient balance")
        self._balance -= amount


account = BankAccount(1000)
account.deposit(500)
account.withdraw(200)
print(account.balance)  # 1300

এখানে public interface হলো deposit(), withdraw() এবং read-only balance property। Internal attribute _balance সরাসরি modify না করে method দিয়ে পরিবর্তনের convention রাখা হয়েছে।

Python-specific note: Python Java/C++-এর মতো সাধারণ private field enforcement দেয় না। _balance convention মাত্র; code চাইলে account._balance access করতে পারে। তাই encapsulation মূলত API design, convention এবং validation-এর সমন্বয়।
Interview answer: Encapsulation data ও behavior-কে class-এর মধ্যে সংগঠিত করে এবং controlled interface দিয়ে state access/change করতে উৎসাহিত করে। Python-এ underscore convention, name mangling এবং @property ব্যবহার করা হয়; এগুলো strict security boundary নয়।
07What is Inheritance in Python?

মূল ধারণা

Inheritance হলো এমন একটি mechanism, যেখানে একটি class অন্য class-এর attribute ও method inherit করে। যে class inherit করে সেটি subclass/child class; যেখান থেকে inherit করে সেটি superclass/base class। এটি shared behavior reuse এবং subtype relationship প্রকাশ করতে পারে।

PYTHON 3
class Animal:
    def eat(self):
        return "Eating"

class Dog(Animal):
    def bark(self):
        return "Woof!"

dog = Dog()
print(dog.eat())   # Inherited method
print(dog.bark())  # Dog's own method

Method Overriding

Subclass parent-এর method একই নামে define করলে subclass-এর implementation lookup-এ অগ্রাধিকার পায়। এটিই method overriding। Parent implementation-ও প্রয়োজন হলে super() দিয়ে call করা যায়।

OVERRIDING
class Animal:
    def speak(self):
        return "Some sound"

class Dog(Animal):
    def speak(self):
        return "Bark"

print(Dog().speak())  # Bark

Inheritance-এর ধরন

  • Single: একটি subclass একটি base class inherit করে।
  • Multiple: একটি subclass একাধিক base class inherit করে।
  • Multilevel: একটি class আরেকটি subclass থেকে inherit করে—যেমন A → B → C।
  • Hierarchical: একাধিক subclass একই base class inherit করে।
  • Hybrid: একাধিক inheritance pattern একসঙ্গে থাকে।

super() এবং MRO

super() শুধু “direct parent”-কে call করার shortcut নয়। এটি Method Resolution Order (MRO) অনুযায়ী পরবর্তী class-এ method lookup চালায়। Multiple inheritance-এ cooperative design-এর জন্য প্রতিটি class-এর super() ব্যবহার এবং compatible method signatures গুরুত্বপূর্ণ। MRO দেখতে ClassName.mro() ব্যবহার করা যায়।

MRO INSPECTION
class A: pass
class B(A): pass
class C(B): pass

print(C.mro())
Design caution: শুধু code reuse করার জন্য inheritance ব্যবহার করা উচিত নয়। Subclass-কে base class-এর contract বজায় রাখতে হবে। “is-a” relationship না থাকলে composition অনেক সময় ভালো design হয়।
Interview answer: Inheritance subclass-কে base class-এর behavior reuse বা override করতে দেয়। Python MRO দিয়ে method lookup order নির্ধারণ করে; super() সেই MRO-র পরবর্তী implementation-এ যেতে সাহায্য করে।
08What is Polymorphism in Python?

মূল ধারণা

Polymorphism অর্থ একই interface বা operation বিভিন্ন object-এর ক্ষেত্রে ভিন্ন behavior দিতে পারে। Caller-কে প্রতিটি concrete class-এর internal implementation জানতে হয় না; প্রয়োজনীয় interface থাকলেই কাজ করা যায়।

Method overriding দিয়ে polymorphism

PYTHON 3
class Dog:
    def speak(self):
        return "Bark"

class Cat:
    def speak(self):
        return "Meow"

def make_speak(animal):
    print(animal.speak())

make_speak(Dog())  # Bark
make_speak(Cat())  # Meow

make_speak() Dog বা Cat class-এর নাম check করে না। এটি শুধু ধরে নেয় object-এ callable speak() method আছে। এই approach duck typing-এর একটি উদাহরণ।

Duck Typing

Python-এ অনেক ক্ষেত্রে object-এর exact type-এর চেয়ে object কী operation support করে সেটি বেশি গুরুত্বপূর্ণ। প্রচলিত কথাটি হলো: “If it walks like a duck and quacks like a duck, it can be treated as a duck.” অর্থাৎ প্রয়োজনীয় behavior থাকলে object-টি ব্যবহার করা যায়।

Operator overloading

Special method implement করে built-in operator-এর behavior custom করা যায়। যেমন __add__() implement করলে + operator object-এর জন্য নির্দিষ্ট behavior পেতে পারে।

OPERATOR OVERLOADING
class Money:
    def __init__(self, amount):
        self.amount = amount

    def __add__(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        return Money(self.amount + other.amount)

total = Money(100) + Money(50)
print(total.amount)  # 150

Polymorphism এবং inheritance কি একই?

না। Inheritance হলো class-এর মধ্যে relationship ও reuse mechanism। Polymorphism হলো একই interface-এর মাধ্যমে বিভিন্ন implementation ব্যবহার করার capability। Inheritance polymorphism implement করার একটি উপায়, কিন্তু Python-এ duck typing বা Protocol-based structural typing দিয়েও polymorphic design করা যায়।

Interview answer: Polymorphism একই interface দিয়ে ভিন্ন object-এর ভিন্ন implementation ব্যবহার করতে দেয়। Python-এ method overriding, duck typing এবং operator overloading এর পরিচিত উদাহরণ।
09What is Abstraction in Python?

মূল ধারণা

Abstraction হলো কোনো system-এর essential operation বা contract সামনে রাখা এবং implementation detail caller-এর কাছ থেকে আড়ালে রাখা। Caller জানে কী operation পাওয়া যাবে, কিন্তু প্রতিটি implementation কীভাবে কাজ করে তা জানার প্রয়োজন হয় না।

Python ABC দিয়ে abstraction

abc module-এর ABC এবং @abstractmethod ব্যবহার করে abstract base class তৈরি করা যায়। Abstract method implement না করা subclass সাধারণত instantiate করা যায় না।

ABSTRACT BASE CLASS
from abc import ABC, abstractmethod

class PaymentGateway(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

class StripeGateway(PaymentGateway):
    def pay(self, amount):
        return f"Paid {amount} using Stripe"

class BkashGateway(PaymentGateway):
    def pay(self, amount):
        return f"Paid {amount} using bKash"

gateway = StripeGateway()
print(gateway.pay(1000))

PaymentGateway একটি contract define করেছে: concrete gateway-কে pay() implement করতে হবে। Business logic এই common interface-এর উপর নির্ভর করতে পারে, নির্দিষ্ট provider-এর implementation-এর উপর নয়।

Abstract class বনাম normal class

  • Normal class সাধারণত সরাসরি instantiate করা যায়।
  • Abstract class-এ abstract method থাকতে পারে; abstract method implement না করা subclass instantiate করা যায় না।
  • Abstract class-এ concrete method, attribute এবং shared implementation-ও থাকতে পারে।

Abstraction বনাম Encapsulation

Abstraction প্রশ্ন করে: “কোন operation বা contract expose করা হবে?” Encapsulation প্রশ্ন করে: “State এবং implementation কীভাবে organize ও controlled access-এর মধ্যে রাখা হবে?” দুটি related, কিন্তু এক নয়।

সতর্কতা: Python-এ ABC ব্যবহার করলেই implementation detail automatically secure বা hidden হয়ে যায় না। ABC মূলত interface contract enforce করতে সাহায্য করে; এটি security mechanism নয়।
Interview answer: Abstraction essential interface expose করে এবং implementation detail caller-এর কাছ থেকে আলাদা রাখে। Python-এ abc.ABC ও @abstractmethod দিয়ে abstract contract define করা যায়।
10Composition vs Inheritance — পার্থক্য কী?

মূল ধারণা

Inheritance সাধারণত “is-a” relationship প্রকাশ করে: Dog is an Animal। Composition “has-a” relationship প্রকাশ করে: Car has an Engine। Composition-এ একটি object অন্য object-কে attribute হিসেবে ধরে এবং তার behavior ব্যবহার করে।

Inheritance example

INHERITANCE
class Engine:
    def start(self):
        return "Engine started"

class ElectricEngine(Engine):
    pass

class Car(ElectricEngine):
    pass

উপরের design-এ Car-কে Engine-এর subclass করা হয়েছে। কিন্তু বাস্তবে Car হলো Engine নয়; Car-এর একটি Engine থাকে। তাই relationship-টি inheritance দিয়ে প্রকাশ করা ঠিক model নয়।

Composition example

COMPOSITION
class Engine:
    def start(self):
        return "Engine started"

class Car:
    def __init__(self, engine):
        self.engine = engine

    def start(self):
        return self.engine.start()

engine = Engine()
car = Car(engine)

print(car.start())

এখানে Car object-এর মধ্যে Engine object রাখা হয়েছে। Car নিজের start operation-এর জন্য Engine-এর behavior delegate করছে। Engine implementation আলাদা class হওয়ায় প্রয়োজন অনুযায়ী অন্য compatible engine দেওয়া যায়।

Comparison

  • Relationship: Inheritance = is-a; Composition = has-a/uses-a।
  • Reuse: Inheritance base class-এর behavior inherit করে; Composition অন্য object-এর behavior delegate করে ব্যবহার করে।
  • Coupling: Deep inheritance hierarchy subclass-কে base class-এর design-এর সঙ্গে tightly couple করতে পারে। Composition সাধারণত dependency আলাদা করে এবং replacement সহজ করে।
  • Flexibility: Composition-এ constructor বা setter দিয়ে dependency inject করা যায়; runtime-এ collaborator বদলানোও সম্ভব, যদি design তা support করে।
  • Polymorphism: দুই approach-ই polymorphism support করতে পারে—inheritance subtype দিয়ে, composition collaborator-এর common interface/duck typing দিয়ে।

কখন কোনটি বেছে নেওয়া উচিত?

  • Subclass সত্যিই base class-এর subtype এবং base class-এর contract ঠিকভাবে মানতে পারলে inheritance ব্যবহার করা যায়।
  • একটি class অন্য component-এর service ব্যবহার করলে বা dependency replaceable রাখতে হলে composition ভালো পছন্দ।
  • শুধু code reuse-এর জন্য inheritance hierarchy তৈরি না করে composition বিবেচনা করা উচিত।
Interview answer: Inheritance “is-a” relationship এবং subtype behavior প্রকাশ করে; Composition “has-a/uses-a” relationship-এ অন্য object-এর functionality ব্যবহার করে। Flexible, loosely coupled design-এর জন্য composition প্রায়ই ভালো default choice, তবে সঠিক subtype relationship থাকলে inheritance উপযুক্ত।
