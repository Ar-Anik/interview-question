Python Asyncio — Interview Questions 21–30

Event Loop, Coroutine, async/await, Task, Future, gather(), Blocking Code, Sync vs Async & Async I/O

সংক্ষিপ্ত উত্তর

Event Loop হলো asyncio-এর মূল execution mechanism, যা asynchronous tasks ও callbacks schedule করে এবং I/O-এর জন্য অপেক্ষার সময় অন্য ready কাজ চালাতে পারে।

সহজভাবে

একটি async application-এ অনেক coroutine থাকতে পারে। Event loop ঠিক করে কোন কাজ এখন চালানো যাবে এবং কোন কাজ I/O-এর জন্য অপেক্ষা করছে।

Coroutine A → await I/O → অপেক্ষা
↓
Event Loop → Coroutine B চালায়
↓
Coroutine B → await I/O → অপেক্ষা
↓
Event Loop → A-এর I/O complete হলে A resume করে

Example

import asyncio

async def main():
    print("Hello")
    await asyncio.sleep(1)
    print("World")

asyncio.run(main())

asyncio.run(main()) সাধারণভাবে event loop চালিয়ে main() coroutine execute করে এবং শেষে loop বন্ধ করে।

Event Loop কী করে?

  • Coroutine/task schedule করে।
  • Ready callbacks ও tasks চালায়।
  • Async I/O completion-এর জন্য অপেক্ষা করে।
  • await-এর কারণে current coroutine suspend হলে অন্য ready কাজ চালাতে পারে।
Important: Event loop নিজে CPU-bound code-কে multiple CPU core-এ parallelভাবে execute করে না। দীর্ঘ CPU-bound synchronous code event loop block করতে পারে।
Interview line: The event loop is the core execution mechanism of asyncio that schedules asynchronous tasks and handles I/O readiness so multiple I/O-bound operations can make progress cooperatively.

সংক্ষিপ্ত উত্তর

async def দিয়ে defined function call করলে সাধারণ function-এর মতো সরাসরি result পাওয়া যায় না; এটি একটি coroutine object তৈরি করে। Coroutine object asynchronous execution-এর জন্য awaitable।

Example

import asyncio

async def fetch_data():
    await asyncio.sleep(1)
    return "data"

coro = fetch_data()

result = asyncio.run(coro)
print(result)

fetch_data() call করলে একটি coroutine object তৈরি হয়। Event loop-এর মাধ্যমে coroutine চালানো যায়।

মূল বৈশিষ্ট্য

  • async def একটি coroutine function define করে।
  • Call করলে coroutine object পাওয়া যায়।
  • Coroutine-কে await করা যায়।
  • Coroutine-কে Task হিসেবে schedule করা যায়।
  • await-এ পৌঁছালে coroutine suspend হয়ে event loop-কে অন্য কাজের সুযোগ দিতে পারে।
Coroutine: একটি awaitable asynchronous computation।
Task: একটি coroutine-কে event loop-এ schedule ও track করা object।
Interview line: A coroutine is an awaitable object produced by calling an async def function; it can be awaited directly or scheduled as a Task.

সংক্ষিপ্ত উত্তর

async asynchronous programming syntax-এর অংশ। সবচেয়ে common form async def, যা একটি coroutine function define করে।

async def fetch_user():
    return {"id": 1, "name": "Anik"}

fetch_user() call করলে dictionary সরাসরি পাওয়া যায় না; একটি coroutine object পাওয়া যায়।

import asyncio

async def fetch_user():
    return {"id": 1, "name": "Anik"}

async def main():
    result = await fetch_user()
    print(result)

asyncio.run(main())

আরও দুইটি async syntax

async with asynchronous context manager এবং async for asynchronous iteration-এর জন্য ব্যবহৃত হয়।

Interview line: async is used to define asynchronous operations, most commonly through async def, which creates coroutine functions.

সংক্ষিপ্ত উত্তর

await একটি awaitable-এর completion/result-এর জন্য অপেক্ষা করার syntax। Coroutine-এর ভিতরে এটি ব্যবহার করা হয় এবং waiting-এর সময় current coroutine event loop-কে control ফিরিয়ে দিতে পারে।

import asyncio

async def fetch_data():
    await asyncio.sleep(2)
    return "data"

async def main():
    result = await fetch_data()
    print(result)

asyncio.run(main())

এখানে কী হচ্ছে?

  1. fetch_data() coroutine object তৈরি করে।
  2. await তার completion-এর জন্য অপেক্ষা করে।
  3. যখন coroutine I/O-এর জন্য অপেক্ষা করে, event loop অন্য ready task চালাতে পারে।
  4. Operation complete হলে coroutine resume করে এবং result পাওয়া যায়।
Important: await মানে পুরো application/thread block করা নয়। তবে awaited operation-এর implementation যদি blocking synchronous code হয়, event loop block হতে পারে।
Interview line: await waits for an awaitable and allows the current coroutine to suspend so the event loop can run other work.

সংক্ষিপ্ত উত্তর

asyncio.Task হলো event loop-এর মধ্যে একটি coroutine-কে schedule এবং track করার object। Task তৈরি করলে coroutine execution-এর জন্য event loop-এ schedule হয়।

import asyncio

async def work(name):
    await asyncio.sleep(1)
    return f"{name} done"

async def main():
    task1 = asyncio.create_task(work("A"))
    task2 = asyncio.create_task(work("B"))

    result1 = await task1
    result2 = await task2

    print(result1)
    print(result2)

asyncio.run(main())

Coroutine বনাম Task

Coroutine: async def function call-এর ফল হিসেবে তৈরি awaitable object।
Task: coroutine-কে event loop-এ schedule করে execution manage/track করে।

একটি coroutine সরাসরি await করলে current coroutine সেটির completion-এর জন্য অপেক্ষা করে। একাধিক coroutine আগে Task হিসেবে schedule করলে তাদের I/O waiting overlap করতে পারে।

Interview line: A Task wraps and schedules a coroutine for execution by the event loop and provides a handle for awaiting or monitoring it.

সংক্ষিপ্ত উত্তর

asyncio.Future হলো একটি low-level awaitable object, যা asynchronous operation-এর ভবিষ্যৎ result বা exception-এর placeholder হিসেবে কাজ করে।

Future created
↓
Result not ready
↓
Operation completes
↓
Future receives result / exception
↓
await future → result

Task বনাম Future

Task হলো Future-এর specialized form যা coroutine execution schedule করে। Future সাধারণভাবে low-level asynchronous result placeholder হিসেবে কাজ করে।

import asyncio

async def main():
    loop = asyncio.get_running_loop()
    future = loop.create_future()

    loop.call_later(1, future.set_result, "Done")

    result = await future
    print(result)

asyncio.run(main())

এখানে Future প্রথমে incomplete। পরে set_result() call হলে Future complete হয় এবং await future result return করে।

Important: Application code-এ Future সাধারণত সরাসরি create করার প্রয়োজন কম। High-level APIs বেশি ব্যবহার করা হয়। Future asyncio internals ও low-level integration-এ গুরুত্বপূর্ণ।
Interview line: A Future is a low-level awaitable placeholder for a result that becomes available later; a Task is a Future-like object that runs a coroutine.

সংক্ষিপ্ত উত্তর

asyncio.gather() একাধিক awaitable-কে concurrently schedule/await করে এবং তাদের results input order অনুযায়ী list-এ return করে।

import asyncio

async def fetch(name, delay):
    await asyncio.sleep(delay)
    return name

async def main():
    results = await asyncio.gather(
        fetch("A", 2),
        fetch("B", 1),
        fetch("C", 3),
    )
    print(results)

asyncio.run(main())

এখানে I/O waits overlap করলে total duration সাধারণভাবে সব duration-এর যোগফল নয়; longest operation-এর কাছাকাছি হতে পারে, runtime overhead বাদ দিয়ে।

Result order

Execution order এবং result order একই নয়। B আগে finish করলেও result হবে:

["A", "B", "C"]

Exception handling

Default behavior-এ একটি awaitable exception দিলে gather() সেই exception propagate করতে পারে। return_exceptions=True দিলে exceptions result list-এর element হিসেবে পাওয়া যায়।

results = await asyncio.gather(
    task_a(),
    task_b(),
    return_exceptions=True
)
Interview line: asyncio.gather() runs multiple awaitables concurrently and returns their results in the same order as the awaitables were passed.

মূল সমস্যা

Async application-এর event loop cooperative concurrency ব্যবহার করে। Event-loop thread-এ blocking synchronous operation চালালে operation শেষ না হওয়া পর্যন্ত অন্য async tasks চালানো যায় না।

Bad example

import asyncio
import time

async def bad():
    time.sleep(5)  # blocking!

async def main():
    await asyncio.gather(
        bad(),
        bad(),
        bad(),
    )

asyncio.run(main())

time.sleep() event loop block করে। তাই concurrency benefit নষ্ট হয়।

Correct async operation

import asyncio

async def good():
    await asyncio.sleep(5)

async def main():
    await asyncio.gather(
        good(),
        good(),
        good(),
    )

asyncio.run(main())

asyncio.sleep() current coroutine suspend করে এবং event loop অন্য ready coroutine চালাতে পারে।

Blocking library ব্যবহার করতেই হলে

import asyncio

def blocking_work():
    return "done"

async def main():
    result = await asyncio.to_thread(blocking_work)
    print(result)

asyncio.run(main())

asyncio.to_thread() blocking synchronous function-কে worker thread-এ offload করার জন্য উপযোগী, বিশেষ করে blocking I/O-এর ক্ষেত্রে।

Important: Traditional GIL-enabled CPython-এ to_thread() CPU-bound pure-Python work-এর জন্য সাধারণত CPU parallelism solve করে না।
Interview line: Blocking synchronous code inside the event-loop thread can block all other async tasks. Use async-compatible APIs or offload blocking work appropriately.

Sync

Synchronous execution-এ একটি operation শেষ হওয়ার পর পরবর্তী operation-এ যাওয়া হয়। Blocking I/O call return না করা পর্যন্ত execution path অপেক্ষা করতে পারে।

def fetch():
    response = requests.get("https://example.com")
    return response

Async

Asynchronous execution-এ awaitable I/O-এর জন্য অপেক্ষা করার সময় current coroutine suspend হয়ে event loop অন্য ready async task চালাতে পারে।

async def fetch():
    response = await async_client.get("https://example.com")
    return response

মূল পার্থক্য

Sync: Blocking operation-এর সময় execution path অপেক্ষা করতে পারে।
Async: Awaitable I/O-এর জন্য অপেক্ষার সময় অন্য async work progress করতে পারে।

Async মানেই faster?

না। Async সব workload-এর জন্য faster নয়। High-concurrency I/O-bound workload-এ এটি resource utilization ও throughput improve করতে পারে।

CPU-bound work event loop-এ সরাসরি চালালে loop block হতে পারে; workload অনুযায়ী multiprocessing বা অন্য CPU execution strategy দরকার হতে পারে।

Interview line: Synchronous execution generally waits for an operation to complete, while asynchronous execution can suspend an I/O-bound operation and let other tasks make progress.

সংক্ষিপ্ত উত্তর

Async database/API call হলো async-compatible client/driver ব্যবহার করে I/O operation করা, যাতে response-এর জন্য অপেক্ষার সময় event loop অন্য async task চালাতে পারে।

Async API example

import asyncio
import httpx

async def fetch_user(client, user_id):
    response = await client.get(
        f"https://example.com/users/{user_id}"
    )
    return response.json()

async def main():
    async with httpx.AsyncClient() as client:
        users = await asyncio.gather(
            fetch_user(client, 1),
            fetch_user(client, 2),
            fetch_user(client, 3),
        )
        print(users)

asyncio.run(main())

Flow

Async application
↓
Async API request
↓
await network I/O
↓
Event Loop অন্য task চালায়
↓
Response ready
↓
Coroutine resume করে

Async database example

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

async def get_users(session: AsyncSession):
    result = await session.execute(
        select(User)
    )
    users = result.scalars().all()
    return users

await session.execute(...) database I/O-এর জন্য asynchronous waiting point।

সবচেয়ে গুরুত্বপূর্ণ

শুধু function-এর সামনে async লিখলেই database/API call asynchronous হয় না। Underlying library/driver-ও async-compatible হতে হবে।

Wrong:
async def get_data():
    response = requests.get(url)  # blocking
    return response
এটি async function হলেও requests.get() blocking call; এটি event loop block করতে পারে।

কখন useful?

  • High-concurrency API server
  • অনেক external API call
  • Concurrent database I/O
  • Network-heavy services
  • WebSocket ও long-lived connections
Interview line: Async database/API calls use async-compatible clients and awaitable I/O so the event loop can handle other tasks while waiting for database or network responses.
