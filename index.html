Python Core — Questions 1–10

প্রতিটি question-এ click করলে answer খুলবে। Explanation-গুলো interview-এর জন্য concise রাখা হয়েছে, তবে concept পরিষ্কার করার জন্য প্রয়োজনীয় description ও example যোগ করা হয়েছে।

Interview strategy: প্রথমে নিজের ভাষায় concept বলুন → তারপর mechanism বলুন → শেষে ছোট example দিন। “Interview Answer” অংশটি short spoken answer হিসেবে ব্যবহার করা যাবে।
1 Python interpreted vs compiled

Python interpreted নাকি compiled?

Python-কে শুধু “interpreted language” বলা technically incomplete। Python source code সাধারণত প্রথমে bytecode-এ compile হয়, তারপর Python runtime সেই bytecode execute করে।

Flow

.py source code
      ↓
Python compiler
      ↓
bytecode
      ↓
Python Virtual Machine (PVM)
      ↓
execution

CPython-এর ক্ষেত্রে source code থেকে bytecode তৈরি করার compilation step আছে। এরপর CPython-এর virtual machine bytecode execute করে। তাই “Python is interpreted” কথাটি সাধারণত runtime execution-এর nature বোঝাতে ব্যবহৃত হয়; এটি Python-এর পুরো execution process-এর সম্পূর্ণ description নয়।

Interview Answer Python-কে সাধারণভাবে interpreted language বলা হয়, কিন্তু CPython-এ source code প্রথমে bytecode-এ compile হয় এবং পরে Python Virtual Machine সেই bytecode execute করে। তাই Python-এর execution model-এ compilation এবং interpretation/execution—দুইটি ধাপ আছে।
2 Python execution model

Python execution model কী?

Python execution model বলতে source code কীভাবে runtime-এ execute হয় সেই process বোঝায়। CPython ধরে সহজ flow: 

Python source (.py)
        ↓
Parsing / compilation
        ↓
Code object containing bytecode
        ↓
CPython runtime / bytecode evaluation
        ↓
Result

Python source থেকে code object তৈরি হয়। Code object-এর মধ্যে bytecode থাকে এবং CPython runtime সেটি execute করে। Imports-এর ক্ষেত্রে compiled bytecode cache করা হতে পারে, সাধারণত __pycache__-এর মধ্যে।

গুরুত্বপূর্ণ: এই flow CPython-এর জন্য বলা হচ্ছে। “Python language” এবং “CPython implementation” এক জিনিস নয়; Python-এর অন্য implementation থাকতে পারে।

Interview Answer CPython-এ Python source code compile হয়ে code object এবং bytecode তৈরি করে। তারপর CPython runtime সেই bytecode execute করে এবং program-এর result তৈরি করে।
3 CPython

CPython কী?

CPython হলো Python programming language-এর একটি implementation, এবং এটি সবচেয়ে প্রচলিত implementation। CPython মূলত C দিয়ে implement করা।

যখন Python install করা হয় এবং python command ব্যবহার করা হয়, সাধারণত CPython interpreter-ই ব্যবহার করা হচ্ছে—যদি অন্য implementation আলাদাভাবে install না করা হয়ে থাকে।

CPython কী করে?

  • Python source code parse ও compile করে code object/bytecode তৈরি করে।
  • Python bytecode execute করে।
  • Python objects, memory management এবং runtime-এর অনেক core behavior পরিচালনা করে।

CPython-এর reference counting এবং cyclic garbage collector-এর মাধ্যমে memory management হয়। Python language-এর সব implementation একই internal mechanism ব্যবহার করবে—এমন ধরে নেওয়া ঠিক নয়।

Interview Answer CPython হলো Python-এর একটি implementation, যা C দিয়ে লেখা এবং সবচেয়ে বেশি ব্যবহৃত। এটি Python source code-কে bytecode-এ compile করে এবং runtime-এ সেই bytecode execute করে।
4 Python bytecode

Python bytecode কী?

Bytecode হলো Python source code-এর একটি intermediate representation, যা Python virtual machine/runtime execute করতে পারে। 

def add(a, b):
    return a + b

এই function compile হওয়ার পর CPython-এর code object-এর মধ্যে bytecode instructions থাকে। এগুলো CPU-এর native machine instructions-এর সমান নয়। CPython runtime এগুলো execute করে।

Bytecode দেখা

import dis

def add(a, b):
    return a + b

dis.dis(add)

Python version অনুযায়ী bytecode instruction-এর নাম ও structure পরিবর্তিত হতে পারে। তাই একটি নির্দিষ্ট instruction list সব Python version-এর জন্য একই ধরে নেওয়া ঠিক নয়।

Interview Answer Python bytecode হলো source code থেকে তৈরি intermediate instructions, যা CPython runtime execute করে। এটি CPU-এর native machine code নয় এবং Python version অনুযায়ী bytecode instructions পরিবর্তিত হতে পারে।
5 .pyc files

.pyc file কী?

.pyc হলো Python source module-এর compiled bytecode cache file। CPython সাধারণত imported modules-এর bytecode __pycache__ directory-তে cache করতে পারে। 

project/
├── app.py
└── __pycache__/
    └── app.cpython-XXX.pyc

এর উদ্দেশ্য হলো একই source module আবার import করার সময় bytecode compilation-এর প্রয়োজন হলে তা কমানো। তবে .pyc থাকলেই Python source compile করা সম্পূর্ণভাবে এড়িয়ে যাবে—এমন নয়; CPython cache validity যাচাই করে।

.pyc সাধারণত source code-এর replacement নয়। Source code পরিবর্তন হলে cached bytecode invalid হতে পারে এবং নতুন bytecode তৈরি হতে পারে।

Interview Answer .pyc হলো compiled bytecode-এর cache file। CPython সাধারণত __pycache__-এ এটি রাখে, যাতে compatible cached bytecode reuse করা যায় এবং import-এর সময় অপ্রয়োজনীয় recompilation কমে।
6 Variables and object references

Python variable কীভাবে কাজ করে?

Python-এ variable-কে সাধারণভাবে object-এর name/reference হিসেবে ভাবা সবচেয়ে accurate। Variable নিজে আলাদা box-এর মধ্যে value store করে—এভাবে Python-কে বোঝা ঠিক নয়। 

x = [10, 20]
y = x

y.append(30)

print(x)  # [10, 20, 30]
print(y)  # [10, 20, 30]

এখানে x এবং y একই list object-কে reference করছে। তাই y.append(30) করলে একই object পরিবর্তিত হওয়ায় x-এর মাধ্যমে দেখলেও পরিবর্তন দেখা যায়।

Assignment-এর অর্থ

a = 10
b = a

b = 20

এখানে b = 20 করার সময় b নতুন integer object-এর দিকে reference করে। a আগের object-এর reference হিসেবেই থাকে।

Interview Answer Python variable মূলত একটি name/reference, যা একটি object-এর দিকে নির্দেশ করে। Assignment সাধারণত object copy করে না; name-কে object-এর সাথে bind করে। তাই একই mutable object-এর একাধিক reference থাকলে mutation সব reference থেকে দেখা যায়।
7 Mutable vs immutable objects

Mutable vs Immutable কী?

Mutable object তৈরি হওয়ার পরে তার content/state পরিবর্তন করা যায়। Immutable object-এর existing object-এর value/state পরিবর্তন করা যায় না; পরিবর্তনের মতো operation করলে সাধারণত নতুন object তৈরি হয়।

Common examples

  • Mutable: list, dict, set
  • Immutable: int, float, bool, str, tuple, frozenset
# Mutable
items = [1, 2]
items.append(3)

# Immutable
name = "Anik"
name = name + " Rob"

দ্বিতীয় উদাহরণে পুরোনো string object-এর content পরিবর্তন হয়নি। নতুন string value তৈরি হয়েছে এবং name নতুন object-এর দিকে bind হয়েছে।

“Immutable variable” বলা ঠিক নয়; mutability একটি object-এর property। একইভাবে tuple immutable হলেও tuple-এর ভিতরে mutable object থাকলে সেই nested object পরিবর্তিত হতে পারে।

Interview Answer Mutable object-এর state পরিবর্তন করা যায়, যেমন list বা dict। Immutable object-এর existing state পরিবর্তন করা যায় না, যেমন int বা str। Immutable object-এর পরিবর্তনের মতো operation করলে সাধারণত নতুন object তৈরি হয়।
8 is vs ==

is এবং ==-এর পার্থক্য

== দুই object-এর value/equality compare করে। is দুই reference একই object-কে refer করছে কি না তা check করে। 

a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True
print(a is b)  # False

দুই list-এর content একই, তাই == True। কিন্তু দুইটি আলাদা list object, তাই is False।

is কোথায় ব্যবহার করবেন?

value = None

if value is None:
    print("No value")

None check করার জন্য is None ব্যবহার করা standard practice। সাধারণ value comparison-এর জন্য == ব্যবহার করা উচিত।

Interview Answer == equality বা value comparison করে, আর is object identity comparison করে—অর্থাৎ দুই reference একই object-কে refer করছে কি না। তাই None check করতে সাধারণত is None ব্যবহার করি।
9 id()

id() কী?

id(obj) একটি object-এর identity-এর জন্য একটি integer return করে। Object যতক্ষণ জীবিত থাকে, সেই object-এর identity unique থাকে। 

a = []
b = a

print(id(a) == id(b))  # True

এখানে a এবং b একই object-কে reference করছে, তাই তাদের id() একই।

CPython-এ id() সাধারণত object-এর memory address-এর সাথে সম্পর্কিত implementation detail হিসেবে দেখা যায়। কিন্তু Python language level-এ id()-কে সরাসরি “memory address” বলা উচিত নয়, কারণ অন্য Python implementations একইভাবে implement করতেই হবে এমন নয়।

Interview Answer id() একটি object-এর identity-এর জন্য integer দেয়। একই সময়ে জীবিত থাকা দুইটি আলাদা object-এর identity আলাদা হবে। CPython-এ এটি সাধারণত memory address-এর সাথে সম্পর্কিত হলেও Python-এর general rule হিসেবে একে memory address বলা ঠিক নয়।
10 Python data types

Python-এর প্রধান data types কী?

Python dynamically typed language। একটি variable-এর আলাদা করে type declaration লিখতে হয় না; object-এর type runtime-এ নির্ধারিত হয়।

Common built-in types

  • Numeric: int, float, complex
  • Boolean: bool
  • Text: str
  • Sequence: list, tuple, range
  • Mapping: dict
  • Set types: set, frozenset
  • Binary: bytes, bytearray, memoryview
  • Null value: NoneType (যার একমাত্র সাধারণ value হলো None)
age = 25                  # int
price = 99.5              # float
name = "Anik"              # str
skills = ["Python", "SQL"] # list
point = (10, 20)           # tuple
user = {"id": 1}           # dict
tags = {"python", "api"}   # set
active = True              # bool
value = None               # NoneType

Python-এ সবকিছুই object হিসেবে model করা হয়। type() দিয়ে কোনো object-এর type দেখা যায়: 

print(type(25))       # <class 'int'>
print(type("hello"))  # <class 'str'>
print(type(None))     # <class 'NoneType'>
Interview Answer Python dynamically typed এবং এর common built-in types-এর মধ্যে int, float, complex, bool, str, list, tuple, range, dict, set, frozenset, bytes, bytearray, memoryview এবং NoneType আছে। Variable-এর type আলাদা করে declare করতে হয় না; runtime-এ object-এর type নির্ধারিত থাকে।
